O que é verdade no que os políticos dizem

Checagem de fatos com fonte para conferir.

Frases de políticos de todos os partidos comparadas com dados oficiais e com checagens de agências independentes. O mesmo método vale para todos.

Como estas checagens foram feitas

As checagens foram pesquisadas e redigidas por um assistente automatizado a partir de fontes públicas (dados oficiais e agências de checagem como Aos Fatos e Agência Lupa) e não foram revisadas por especialistas humanos. Cada item mostra as fontes usadas e as limitações: confira antes de compartilhar. Achou um erro? Abra uma issue no GitHub com o link da checagem.

    O que significa cada resultado

    Não encontrar comprovação não é o mesmo que a frase ser falsa: nesse caso o resultado é “Não comprovada”. Investigação, acusação e condenação também são coisas diferentes (veja o dicionário).
